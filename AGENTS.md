This project is a single-file web app using plain HTML, CSS, and JavaScript. GitHub Pages serves the root `index.html`; do not use Flask, Python, a build system, or a framework.

## Project layout

- `AGENTS.md`: project instructions.
- `spec.md`: project requirements and behavior.
- `prompts.md`: request and change log.
- `index.html`: the web app, kept at the repository root for GitHub Pages.
- `00_planning/`: planning notes and sketches.
- `01_data/`: project data files.
- `02_validation/`: hand calculations and test cases.
- `03_output/`: screenshots and exported results.

Save every new file in the appropriate location above. Keep the four root files at the project top level, and put supporting materials in the matching numbered folder.

After each request, add an entry to `prompts.md` describing what was asked, what changed, and whether it worked.
