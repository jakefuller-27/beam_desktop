# Beam Designer

Beam Designer is a Tkinter desktop app for analyzing steel and lumber beams.
It calculates reactions, shear, moment, and deflection, checks sections, and
exports calculation sheets and CSV results.

## Install

```sh
python3 -m pip install -r requirements.txt
```

This installs NumPy and Matplotlib. Tkinter is included with most Python
installations.

## Start

```sh
python3 app.py
```
